What's on the card · spec

  • Assignment banner — sits at the very top so the operator knows who sent this, when, and through what channel. Disappears (or collapses) after first read.
  • Asset block — name + location + live Running / Stopped / Fault status with bilingual signal. Four key telemetry fields in a single row, with updated 12s ago timestamp for trust.
  • Issue summary — severity chip + ID + one-line title + 1–2 line description. The operator's "what am I dealing with" beat.
  • Primary CTA — Start diagnosis → (one job to do). Secondary Can't take this — reassign for when it's not their skill / shift / location.
  • BLOCKED state — red-orange left stripe + ⛔ BLOCKED · HARD GATE chip + plain-English reason ("waiting on supervisor approval"). Shows assignee presence dot (offline = grey) and a pulsing dot with elapsed block time. Two actions: View details and Take over.
  • Related queue — other issues on this asset, sorted by severity, each a tappable row. Stripe color = severity. Schedule / history collapsed at the bottom.
