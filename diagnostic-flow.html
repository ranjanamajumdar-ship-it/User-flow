Design notes

Patterns and motion conventions for the developer / Figma handoff.

Where illustrations live

  • Screen 1 — Aeration tank with the DO-3 probe highlighted red. Sets the scene immediately.
  • Screen 2 — Three mini-tank visuals (A/B/C). Operator's eye matches what they see in reality to the picture.
  • Screen 4 — Choked diffuser strip with crossed-out stones — confirms what the operator just observed.
  • Screen 6 — Air-supply chain diagram (Blower → blocked pipe → empty tank).
  • Screen 7 — Healthy tank with bubbles + pulsing red ring around the sensor — the visual hypothesis.

Motion / animation cues

  • Screen transitions — slide-left forward, slide-right back. 200ms ease-out.
  • Severity badge — soft pulse on Screen 1.
  • Sensor ring (Screen 7) — radius animation, 2s loop.
  • Success icon (Screen 8) — bounce-in (0 → 1.1 → 1) on mount.
  • Option tap — border shifts to brand blue, light ripple from tap point.
  • CTA disabled → enabled — colour transition on option select (Screens 2, 3).

Button placement (Fitts's Law)

  • Primary CTA always full-width at the bottom of the screen.
  • Back button top-left (Jakob's Law — standard).
  • Overflow menu top-right.
  • Step-chip directly under the nav for context.
  • Multi-choice options are large tap targets (60px+ height).

Content hierarchy

  • Step chip tiny — orient the operator without crowding.
  • Question bold, 19px — the one thing they read.
  • Helper 12.5px, ink-3 — read only if needed.
  • Illustration before options — visual answers first, then text.
  • One CTA per screen (Hick's Law).
