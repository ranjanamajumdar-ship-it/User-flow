What stays the same · what changes

Constant chrome (every state)
  • Top state chip — colored purple/blue/red/green so the state is readable in 100ms
  • Asset strip — name + severity + issue title, one line
  • Recipient strip — avatar + name + presence dot + activity sub-line
  • Single CTA — always one, full width
  • Footer ghost link — Open full issue for the rare deep-view need
What morphs per state
  • State 1 (Summary) — reason quote · handoff timestamp · CTA View live progress
  • State 2 (Progress) — step N/M · progress bar · current step · time on step · root-cause chip · last activity · CTA Take back
  • State 2 BLOCKED — same as Progress + inline red BLOCKED card · presence flips to offline · CTA still Take back but visually escalated
  • State 3 (Completion) — green outcome panel · root cause · total time · verification status · CTA Acknowledge & close

The card never asks Op A which state to view — it advances on its own as the underlying issue moves. From Op A's perspective there is only one card in their feed, and it tells them what's happening right now.
