Cross-stage jumps — now disambiguated

  • RCA already known → Intake skips Diagnose, routes straight to Remediate. EVT diagnose_shortcut — Advanced operators only.
  • I know the cause → mid-Diagnose shortcut, same intent as above but exited from a step screen. Same event.
  • False alarm at alert → Create skips everything, lands in Close as STATE = FALSE_ALARM with mandatory reason. Notifies SME for threshold review.
  • Sensor self-recovered → Auto-close detector sees the reading return before operator completes Remediate. Issue goes to STATE = AUTO_CLOSED directly. This is NOT the same as "RCA provided".
  • Failed verify → Operator says "not fixed". Routes back to either Remediate (try again) or Root Cause (wrong diagnosis) based on operator pick.
  • Photo hard-gate failed 3 times → Auto-escalate to supervisor; state stays WAITING_PHOTO until override.
  • Force close / Abort → Supervisor only · requires reason · feeds the review queue.

New states & events added

  • STATES added to the rail: WAITING_STEP_APPROVAL · WAITING_PHOTO · WAITING_COST_APPROVAL · WAITING_VERIFY_APPROVAL · PAUSED · REASSIGNED · AUTO_CLOSED · FALSE_ALARM · FORCE_CLOSED.
  • SPLIT events: SKIPPED · DONT_KNOW · FALLBACK · RETRY · CORRECTED — all separate, each routes differently. SKIP just logs; DON'T_KNOW pauses session and triggers reassignment.
  • Reassignment arc: 4 explicit boxes — trigger → graceful close → context card → Op B takeover — usable mid-Diagnose AND mid-Remediate.
  • Tree-improvement loop: Different RCA · Operator suggestion · Repeated-stop signal — all feed the SME backlog; SME publishes new template version.
  • Review queue actions now have destinations: Reopen · Send-to-SME · Accept (close).
  • Flag new issue is a first-class deviation — creates a fresh issue while preserving the current one.
