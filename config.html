Who runs this flow?

Pick the role that owns this diagnostic. If they're unavailable, it'll auto-escalate.

Primary assignee

Whoever is on shift in this role will be notified first.

Escalation chain

If the primary assignee doesn't respond, the flow climbs this ladder. Drag rows to reorder.

1 Site Engineer (Sharma ji) — primary Notified immediately on flow start
2 Supervisor Escalate after of no response
3 Site Manager Escalate after with no resolution

Skill-type override

If a step needs a different skill type than the assignee has, the system auto-routes that one step. The rest of the flow stays with the primary.
